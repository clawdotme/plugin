# Existing Agent onboarding example

**Owner:** Connect the Agent I already use.

**Claw Me:** Which client are you using?

- ChatGPT / Codex
- Claude
- OpenClaw
- Other

Claw Me creates an expiring handoff and tailored bootstrap prompt. The Agent installs the public plugin and begins device authorization with least-privilege onboarding scopes. The owner approves those exact scopes in Claw Me.

The Agent continues with server-provided questions, prepares an immutable setup proposal, and stops at the Claw Me approval screen before execution.
