# Contributing

Open an issue before proposing a breaking contract change. Keep the plugin thin and preserve owner approval boundaries.

Before submitting a change:

1. Update compatibility and the changelog when behavior changes.
2. Keep `claw-me/` and `skills/claw-me/` identical.
3. Run `./scripts/validate.sh`.
4. Confirm examples contain no real credentials, account identifiers, personal data, or private URLs.
