# Client project proposal

Version 2.1.0 pilot for Templates & Prompts. Open index.html to preview. Example answers are illustrative and inspired by Claw Me, not private customer information.

- Start with this template: make a private copy, then use customizationPrompt from creation-brief.json with the copy's Page URL.
- Build your own version: use creationPrompt and supply your own answers. exampleAnswers records the sample brief; the creation prompt is reconstructed, not a historical transcript.
- Styling: ../_shared/tailwind/README.md. Static HTML/CSS only; no submissions, payment collection, or live data.

HTML and PDF editions share one content source. See ../README.md for the PDF export and review workflow. Native disclosures are expanded in the file edition.
