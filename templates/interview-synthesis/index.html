Theme: context at the point of use

Three example records concern information surrounding the file rather than the file itself. That suggests a prototype should test labels, ownership, and a clear entry point.

Counterexample: another thing to maintain

P04’s example raises a cost that the synthesis must preserve. A new index may be unwelcome if it duplicates an existing routine without making retrieval easier.
