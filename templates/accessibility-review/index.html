Describe the barrier

A useful finding explains what the person is trying to do and how the interface prevents or complicates it. Attach a concrete example rather than a vague instruction to improve accessibility.

Check the repair

Repeat the affected task after the change. Combine automated checks with keyboard review and appropriate assistive-technology testing; no single tool establishes complete accessibility.

Keep the scope visible

Record the pages, components, environments, and methods actually reviewed. In a formal assessment, map findings to the current applicable standard using verified references.
