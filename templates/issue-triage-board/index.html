A useful issue record

Record the page, device, expected result, actual result, and a minimal reproduction. Avoid including private account data in screenshots. Link the verified evidence in the private issue system.

Close with a check

An issue is resolved when the original task works in the affected context and a reviewer confirms the result. A code change alone is not evidence that the user’s problem has gone away.
