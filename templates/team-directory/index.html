Start with responsibility

Ask the named owner about the work, and include enough context to avoid a guessing game. A page link, a concrete question, and a deadline usually make a request easier to answer.

Availability is a guide

The working windows are preferences rather than guarantees. In the real directory, let people review how they are described and decide which contact details are appropriate to share.

When the owner is away

Use the agreed backup route for urgent delivery questions. Routine requests can wait for the next working window. Keep an explicit backup for any responsibility that cannot pause.
