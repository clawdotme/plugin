Test the task that matters to the user.

This fictional test plan covers a handover index on desktop and mobile. It prioritizes finding the correct item, understanding its status, and using its links.

Test setup

Use a controlled example with draft, approved, and archived entries. Include a long title and a missing reference case. Record the browser, viewport, version, and source data.

Failure handling

Describe the expected and actual result with a minimal reproduction. Keep the severity tied to the user’s task and record a named owner for the next action.

Exit criteria

The critical lookup and reference-opening tasks pass, keyboard operation works, and known limitations are reviewed by the release owner. Do not equate a screenshot with complete functional coverage.
