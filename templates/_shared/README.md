# Shared template assets

`portal.css` supplies the Claw Me template palette, spacing, and typography. The HTML files reference these local assets; the build embeds their bytes in each published Page.

The original PNG artwork was generated for Claw Me on 7 September 2026: `lisbon.png` (travel), `studio.png` (design), and `workspace.png` (planning). It illustrates sample content, not real customer work or bookings. The artwork and stylesheet are MIT licensed. Archivo and Bitter retain the included SIL Open Font Licenses.

No external image/font service or browser JavaScript is required.
