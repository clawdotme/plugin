- Build your own version: use creationPrompt and replace the example answers with your own.
- exampleAnswers records the illustrative brief for this edition, not private user data or a historical conversation.
- Styling: ../_shared/tailwind/README.md. Compile scoped Tailwind CSS and bundle it with the page.

Build a day-by-day timeline covering arrival through departure, booking-status notes, packing checklist, rainy-day alternative, and practical details. Distinguish confirmed bookings from ideas; verify time-sensitive details before presenting them as facts. Never book or pay as part of building this page.
